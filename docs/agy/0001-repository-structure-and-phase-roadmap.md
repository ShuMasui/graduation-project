# 1. リポジトリ構成と3段階開発ロードマップの策定

* **ステータス**: 承認済 (Accepted)
* **決定日**: 2026-08-25
* **文脈**: 卒業研究 (高密度EEG解析)

---

## 1. 背景と課題 (Context & Problem Statement)

本卒業研究では、高密度EEG（64ch / 128ch）の生データ前処理、頭部順モデル構築、eLORETA音源推定、大脳皮質アトラス集約、および統計検定・3D可視化という極めて多岐にわたる処理パイプラインを開発する必要があります。
初期段階から過剰に複雑なディレクトリ構造やフレームワークを導入すると、管理コストが増大し、研究の進捗や実験の再現性検証が困難になるリスクがありました。

---

## 2. 決定事項 (Decision Outcome)

以下の基本方針とリポジトリ構成、および3段階の開発ロードマップを決定しました。

### 2.1 最小限のディレクトリ構成とKISS原則
```text
graduate-project/
├── CLAUDE.md                   # プロジェクト方針・開発ガイドライン
├── docs/                       # 設計書・仕様書・論文ドキュメント・ADR
│   ├── exp-reproduce/          # Phase 1 再現実験用ドキュメント群
│   └── agy/                    # アーキテクチャ決定記録 (ADR)
├── exp-reproduce/              # Phase 1 再現実験用プログラム (Python 3.10)
└── eeg-processing/             # Phase 2 卒業研究本番用プログラム
```

### 2.2 3段階の開発ロードマップ
1. **Phase 1: EEG処理プログラムの再現実験 (`exp-reproduce`)**
   - 先行研究（*Gomez-Tapia et al., 2025, Frontiers in Neuroimaging*）の処理パイプラインを再現し、検証基盤を確立する。
2. **Phase 2: 今回の研究におけるプログラムの実装 (`eeg-processing`)**
   - 卒業研究固有の課題・仮説に合わせた解析手法やデータ抽出ロジックを実装する。
3. **Phase 3: 実際のデータ解析**
   - 実験で取得した実データに対する本番解析・統計評価・考察を行う。

---

## 3. 影響と評価 (Consequences)

### メリット (Pros)
- ディレクトリと役割の境界が明確になり、管理・保守コストが最小化された。
- 論文再現（Phase 1）を先行させることで、以降の独自研究プログラム（Phase 2）の妥当性を強固に担保できる。

### デメリット・留意点 (Cons)
- 段階ごとにドキュメントとコードの所在を厳格に切り替える運用が必要となる。
